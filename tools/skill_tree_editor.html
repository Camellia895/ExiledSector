Skill Tree Layout Editor

Mode
Select: drag a node to move it, drag empty canvas to pan, scroll to zoom. Shift-click a node to add/remove it from a multi-selection, or shift-drag empty canvas to marquee-select. Drag any selected node to move the whole group together.

Add: click empty canvas to place a node there.

Link: click two nodes to connect them - each is added to the other's connections, so allocating either one lets you allocate the other. Click the same pair again to unlink.
